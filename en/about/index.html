About

I'm Henrik, a senior .NET consultant in Lidingö, Stockholm. I've written code professionally since 1999, and since 2017 through my own company.

How I work

I've worked in a wide range of industries, most recently finance, insurance and online gaming. I work closely with the people who own the problem and write code that's easy to read, test and maintain. Tests work as executable specifications where that makes sense, and I automate the path to production early.

On AI

I use Claude Code more or less daily, and I build with AI too: the CV chatbot on henrikbecker.net runs on .NET and Semantic Kernel. Language models don't know when they're wrong though, so an Authentic Intelligence has to stay in the loop. More on that →

Off the clock

I build small things to learn new stacks and/or just for fun, including one that is useless on purpose. I'm also a Wim Hof nerd and enjoy open water bathing, which is why I built Dopp.

What I do

  • Backend development in .NET and C#
  • System integration: REST, message queues, WCF and legacy systems
  • Automation & DevOps: CI/CD pipelines, scripting and infrastructure as code (Bicep)
  • Architecture: structuring new projects, untangling old ones, codebase reviews
