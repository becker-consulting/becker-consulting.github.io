About

I'm a senior backend consultant in Lidingö, Stockholm, and I've been writing code professionally since 1999. Since 2017 I've done it through my own one-person company.

How I work

Most of my assignments have been in finance, insurance and online gaming — places where the backend has to be right, not just fast. I lean on agile practices, test-driven development and SOLID design, and I automate the path to production early so that shipping stays boring.

Tests are written as executable specifications where it makes sense, and deploy pipelines are treated as part of the product — built with tools like GitHub Actions and Octopus Deploy.

What I do

  • Backend development in .NET and C#
  • System integration across REST, GraphQL and message queues
  • Automation & DevOps — CI/CD pipelines and infrastructure as code
  • Architecture and technical guidance for the long run
